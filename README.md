## Selected projects

### startingSchool

An educational game for kids to experience starting primary / elementary school.

- Built in TypeScript.
- Repository: [CaomhinB/startingSchool](https://github.com/CaomhinB/startingSchool)

This software was designed to simulate starting primary school for a child aged 4 to 5 years old and to run on a web browser.

It involves simple point-and-click tasks that reveal simple games like colouring-in and stacking blocks.

The game does not store any data on the child, which keeps it compliant with GDPR.

The software was built using a specification document Prd.md (see below)that was input into Claude Code, which then built a web-based App using HTML + CSS + JavaScript.
